# Inkwell — Responsive Blog Application

A beginner-friendly multi-page blog application built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home, sample blogs, search
- `login.html` — Login form
- `register.html` — Register and validation
- `dashboard.html` — Current user's posts, word count, edit/delete
- `create-blog.html` — Create and edit blog posts
- `read-blog.html` — Read a full blog post

## Run it
1. Extract the ZIP file.
2. Open the `blog-application` folder.
3. Double-click `index.html` to open it in your browser. (Recommended: use VS Code with the Live Server extension.)
4. Select **Get started**, register a demo account, then create a blog.

## Features
- Responsive layout for mobile and desktop
- Mobile navigation menu
- Search sample and user-created blogs
- Register/login form validation
- Create, read, update, and delete the signed-in user's posts
- Browser `localStorage` for demo persistence
- Sample blog posts for the home page

## Important security note
This is a frontend learning demo. User details and passwords are stored in browser `localStorage`, which is not secure. Never use a real password. A real application needs a backend, secure password hashing, server-side authentication, and a database.
